Which Mnemosyne is this?

Several unrelated projects share the name. This one is the desktop memory operating system published by XPACEGEMS LLC, at the addresses listed above. It is not the Mnemosyne spaced-repetition flashcard application, and it is not the mnemosyne-oss GitHub organization. Those are different projects by different authors.
