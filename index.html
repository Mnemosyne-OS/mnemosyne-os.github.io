Mnemosyne OS

Everyone is building the intelligence. We build the relationship.

A sovereign, local-first memory operating system. It runs on your own machine and gives an AI a persistent, governed memory of who you are and what you have built together.

Most people already have a word for what they want: a jarvis. Something that knows the whole story, not the last ten messages, and that belongs to them. That is what gets built here, one memory at a time, on hardware you control.

This address is the organization's entry point on GitHub. The product, the documentation and the packages live elsewhere.

Windows

Windows 10 / 11 · x64 Intel or AMD

Installer 185 MB Portable build 184 MB Signed

Code-signed with a Certum certificate, RFC-3161 timestamped: Windows names the publisher instead of saying “unknown publisher”. A recent certificate still has to earn its SmartScreen reputation, so if the blue screen appears, click More info, then Run anyway.

macOS

Apple Silicon · M1 or later, not Intel

.dmg 245 MB Not notarized yet

Apple notarization is under way; until it lands the build is ad-hoc signed, so Gatekeeper may refuse it or call the app damaged. Open it once with right-click (or Ctrl-click) on Mnemosyne OS → Open → Open. If it still blocks: xattr -dr com.apple.quarantine "/Applications/Mnemosyne OS.app"

Linux

x86-64 · ARM not supported

.AppImage 223 MB .deb · Debian / Ubuntu 122 MB No signing gate

Nothing to get past: the .deb installs normally, and the AppImage runs once it is executable. chmod +x Mnemosyne*.AppImage
